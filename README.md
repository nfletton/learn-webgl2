An personal exercise in learning WebGl2.

## References
- [WebGL2 Tutorial](https://webglfundamentals.org/webgl/lessons/webgl2-fundamentals.html)

## Setup and Development
- **Install dependencies:**
  ```bash
  npm install
  ```
- **Start development server:**
  ```bash
  npm run dev
  ```
  Vite will provide a local URL (e.g., `http://localhost:5173`) where the application can be accessed.
- **Build for production:**
  ```bash
  npm run build
  ```
  The production-ready assets will be generated in the `dist` directory.
- **Preview production build:**
  ```bash
  npm run preview
  ```
